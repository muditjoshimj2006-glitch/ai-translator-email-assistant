# AI Translator & Email Assistant

An AI-powered Python application that translates text into multiple languages and generates professional email content using the Google Gemini API.

---

## Features

- Translate text into multiple languages
- Generate professional email content
- Simple command-line interface
- Google Gemini API integration
- Clean and beginner-friendly Python code
- Basic input validation

---

## Technologies Used

- Python
- Google Gemini API
- python-dotenv
- Environment Variables (.env)

---

## Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/ai-translator-email-assistant.git
```

2. Install dependencies

```bash
pip install google-genai python-dotenv
```

3. Create a `.env` file

```env
API_KEY=YOUR_GEMINI_API_KEY
```

4. Run the program

```bash
python main.py
```

---

## How It Works

1. Enter the text you want to translate.
2. Select the target language.
3. The application translates the text using Gemini AI.
4. Choose whether to generate an email.
5. Enter the recipient and subject.
6. The AI generates a professional email using the translated text.
